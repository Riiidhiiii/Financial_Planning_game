# 🎲 Financial Chaos — Life Simulator

**A randomized financial planning board game built with HTML, CSS, and JavaScript.**

## 📌 About the Project

Financial Chaos is an interactive financial literacy game that simulates real-life money decisions. Players progress through different stages of life, make financial choices, and face unpredictable events that affect their savings, investments, debt, and financial health.

The objective is to reach retirement with a healthy financial position while learning how to manage money wisely.

## ✨ Features

- **9 Life Stages:** Career, marriage, EMIs, insurance, emergencies, investments, tax saving, unexpected life events, and retirement.
- **8 Actions Per Round:** Make multiple financial decisions during each life stage.
- **Randomized Events:** Experience salary bonuses, medical expenses, market crashes, unexpected gifts, financial setbacks, and more.
- **Decision-Based Gameplay:** Choose between different strategies, each with different consequences.
- **Financial Education:** Learn practical money-management concepts through lessons after each decision.
- **Live Financial Dashboard:** Track cash, investments, outstanding debt, and financial health.
- **Emergency Fund & Insurance:** Discover how financial protection can reduce the impact of unexpected events.
- **Final Financial Audit:** Review your simulated net worth and financial progress at the end of the game.
- **Responsive Design:** Play on desktop or mobile devices.

## 🛠️ Technologies Used

- **HTML5** — Game structure and content.
- **CSS3** — Styling, layout, animations, and responsive design.
- **JavaScript** — Game logic, random events, dice rolls, financial calculations, and interactive decisions.

No external libraries, frameworks, databases, or installations are required.

## 🚀 How to Run the Game

1. Download or clone the project.
2. Open the project folder.
3. Locate `index.html`.
4. Double-click the file to open it in your web browser.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension.

## 🎮 How to Play

1. Start with your initial cash and investments.
2. Roll the dice to trigger a financial event.
3. Read the situation and review the available choices.
4. Select an action and observe its financial consequences.
5. Read the financial lesson associated with your decision.
6. Complete all 8 actions in the current round.
7. Progress through all 9 life stages.
8. Review your final net worth and financial health.

## 🎯 Project Objective

The project aims to make financial literacy engaging through interactive gameplay. By experiencing simulated financial wins and losses, players can understand why budgeting, emergency savings, responsible borrowing, risk management, and long-term planning are important.
